# ユニットテスト式様書（Unit Test Specification）- Entity層

## 1. テスト概要

### 1.1 テスト対象システム
**システム名**: 社会保险バックエンドサービス（Social Insurance Backend Service）  
**テスト対象クラス**: `PremiumBracket`  
**テスト種別**: ユニットテスト（Unit Test）  
**テスト実施日**: -  
**テスト実施者**: -  
**バージョン**: 0.0.1

### 1.2 テスト環境
- **フレームワーク**: Jakarta Bean Validation
- **テストツール**: JUnit 5, Jakarta Validation API
- **Java バージョン**: 21
- **テストアノテーション**: なし（プレーンなJUnitテスト）

### 1.3 テスト範囲
本テスト式様書は、Entity層のバリデーションテストを対象とする。  
ユニットテストでは、以下の要素をテストする：
- Bean Validationアノテーションによるバリデーション
- 正常系のバリデーション（有効なデータ）
- 異常系のバリデーション（無効なデータ）

### 1.4 ユニットテストの特徴
- Spring Frameworkを使用しないプレーンなJUnitテスト
- Jakarta Bean Validationの`Validator`を直接使用
- データベースや他の依存関係は使用しない
- 高速に実行可能

## 3. テスト項目詳細

### 3.1 TC-E-001: 保険料等級エンティティのバリデーション（正常系）

#### 3.1.1 テスト目的
有効なデータを持つ`PremiumBracket`エンティティが、すべてのバリデーションルールを通過することを確認する。

#### 3.1.2 前提条件
- Jakarta Bean Validationの`Validator`が正しく初期化されていること

#### 3.1.3 テストデータ
| 項目 | 値 |
|-----|-----|
| 等級（grade） | `"32(29)"` |
| 标准报酬（stdRem） | 560,000円 |
| 最小値（minAmount） | 545,000円 |
| 最大値（maxAmount） | 575,000円 |
| 健康保険料（介護なし） | 55,552.00円 |
| 健康保険料（介護あり） | 64,456.00円 |
| 厚生年金保険料 | 102,480.00円 |

#### 3.1.4 テスト手順
1. `PremiumBracket`エンティティを構築する（有効なデータで）
2. `Validator.validate()`を呼び出してバリデーションを実行する
3. バリデーション結果を検証する

#### 3.1.5 期待結果

##### 3.1.5.1 バリデーション結果
- バリデーション違反（`ConstraintViolation`）が0件であること
- `violations.isEmpty()`が`true`であること

#### 3.1.6 判定基準
- バリデーションが成功すること（違反が0件であること）
- すべてのバリデーションアノテーションが正しく機能していること

#### 3.1.7 備考
- このテストは正常系のバリデーションテストである
- すべてのフィールドが有効な値を持つ場合、バリデーションが通過することを確認する
- `@NotNull`、`@NotBlank`、`@DecimalMin`、`@DecimalMax`などのアノテーションが正しく機能することを検証する

---

### 3.2 TC-E-002: 保険料等級エンティティのバリデーション（負の最小値・異常系）

#### 3.2.1 テスト目的
無効なデータ（負の最小値）を持つ`PremiumBracket`エンティティが、バリデーションルールに違反することを確認する。

#### 3.2.2 前提条件
- Jakarta Bean Validationの`Validator`が正しく初期化されていること

#### 3.2.3 テストデータ
| 項目 | 値 |
|-----|-----|
| 等級（grade） | `"32(29)"` |
| 标准报酬（stdRem） | 560,000円 |
| 最小値（minAmount） | -1円（無効な値） |
| 最大値（maxAmount） | 575,000円 |
| 健康保険料（介護なし） | 55,552.00円 |
| 健康保険料（介護あり） | 64,456.00円 |
| 厚生年金保険料 | 102,480.00円 |

#### 3.2.4 テスト手順
1. `PremiumBracket`エンティティを構築する（負の最小値で）
2. `Validator.validate()`を呼び出してバリデーションを実行する
3. バリデーション結果を検証する

#### 3.2.5 期待結果

##### 3.2.5.1 バリデーション結果
- バリデーション違反（`ConstraintViolation`）が1件であること
- 違反のプロパティパスが`"minAmount"`であること
- 違反のメッセージが`"最小值不能为负数"`であること

#### 3.2.6 判定基準
- バリデーションが失敗すること（違反が1件以上であること）
- 違反のプロパティパスが期待値と一致すること
- 違反のメッセージが期待値と一致すること

#### 3.2.7 備考
- このテストは異常系のバリデーションテストである
- `@DecimalMin`アノテーションが正しく機能することを確認する
- 負の値が指定された場合、適切なエラーメッセージが返されることを検証する

## 4. テスト実行方法

### 4.1 テスト実行コマンド
```bash
./gradlew test
```

### 4.2 特定のテストクラスのみ実行
```bash
./gradlew test --tests SocialInsuranceEntityTest
```

### 4.3 特定のテストメソッドのみ実行
```bash
./gradlew test --tests SocialInsuranceEntityTest.testPremiumBracketValidation
```
